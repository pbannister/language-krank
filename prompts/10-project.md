# Project Structure

## Project Structure

- `LICENSE` — the licence this project ships under.
- `.editorconfig` — the editor indentation and line-ending convention.
- `package.json` — the npm package that publishes the `krank` command.
- `package-lock.json` — the npm lockfile for that package.
- `prompts.out/` — generated formal form of the prompt corpus (`make prompts`); not versioned.
