# Feature Index

- `01-site-build.md` — Site Build: generates `site.out/` from `site.in/`.
- `02-project-pages.md` — Project Pages: the standard published page set (status, dashboard, condensed todo/prompts/documents).
- `03-rules-engine.md` — Krank Rules Engine: the notation, interpreter, and renderer.
- `04-browser-demo.md` — Browser Demo: the playground published with the project pages, and the local prompt studio.
- `05-harness-studio.md` — Harness Studio: the DeepSeek Harness client plugin that opens the local studio.

- The site-build and project-pages features are worked examples inherited from the skeleton, not requirements of the rules engine.
