krank — the round trip

A human writes rules in prose. A model compiles them into the formal rule set below. The engine renders the rules back into prose, and a reader compares that prose with the original. The comparison is the check that the compilation kept the meaning; it is a recorded judgement, not a mechanical proof.

The aim is to shrink what the model must hold: in a later iteration it receives the compiled rules and calls the engine to prove conformance, instead of re-reading the full prose. The playground lets you edit a rule set and run it.
