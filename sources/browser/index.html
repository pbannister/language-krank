                        We start with a human-written prompt file.
                    

                    

                        The prompt file contains the original intent of the developer, written in prose.
                    

                    

                        Current models (LLMs) are both impressive and imperfect in their ability to understand natural
                        language.
                    

                    

                        In present, models understand human intent often enough to be useful.
                        Occasionally the model goes astray, sometimes badly.
                        To limit damage, we use sandboxes and design for "blast radius".
                        We cannot count on the model to always understand intent.
                    

                    

                        In the end we need to derive formal rules to more accurately check intent.
                    

                    

                        We want to best use strength of both model and human mind.
                    

                    

                        Models well read and understand natural language.
                        Models can generate formal rules from that understanding.
                        This gets us part of the way.
                        Human review can verify that the model accurately captured intent.
                        But humans are not efficient at reading formal rules.
                    

                    

                        How can we make human review efficient?
                    

                    

                        We use the model to render formal rules back into prose.
                        Further, we use the model to compare the original and generated prose.
                        If they match, then we can be confident that the model captured original intent.
                    

                    

                        Human review is only needed when the original and generated prose do not match.
                        Guided by the model's comparison, with both original and generated prose, we can revise the
                        original so as to better express our intent.
                    

                    

                        In this way, we approach best use of strength for both the model and the human mind.
                    

                    

                        At present the weak points are the prose generated from rules, and the prose comparison.
                        
We hope to improve these weak points over time.
                    

                    

                        The end aim is to augment prose with formal rules.
                        The model can then generate reduced prose, which is better handled by an LLM.
                        The formal rules then provide a more exact and unvaried check of original intent.
                    

                    

                        This page walks the steps of that exchange.
