krank — compile and check

A human writes rules in prose. A model compiles them into a formal rule set; the engine renders the rules back into prose so a reader can compare, and runs them against the project's files. The compile is recorded: this page loads the compiled rule sets, it does not call a model.

The aim is to shrink what the model must hold: in a later iteration it receives the compiled rules and calls the engine to prove conformance, instead of re-reading the full prose. The playground edits a rule set and runs it.
