krank — prompt studio

A human writes intent in prose. A model compiles it into a rule set; the engine renders the rules back into prose, and a reader compares. The compile is recorded: this page loads the candidates, it does not call a model.

The aim is to shrink what the model must hold: the model emits facts, runs krank check, and reads the decision instead of the rules. This page walks the steps of that exchange; the choice you make here is local to the page.

1. The prompt

The prompt is the source. Edit it here to see what the mechanical reducer would drop; the compile itself is recorded, not run.

2. Candidates

The model proposes the rule sets for this prompt. When the prose is unclear, more than one appears; choose the one that reads most faithfully.
